# Vicon／OpenSim SO 工作流

## 确认配置

- 确认动作、目标腿、支撑段、输出目录以及 IK 或 RRA 路线。全身和规定骨盆的单腿方法分别使用相应的输入契约。
- 确认使用原版 Gait2392 最大等长肌力，或将 Rajagopal 模型的对应参数移植到工作副本。保存肌力来源和映射审计。
- 每批询问是否新增四阶 Butterworth 6 Hz 双向零相位低通。确认运动学、力和力矩，或两者，并核查上游滤波历史。选择不新增时可复用适用的已处理输入。见[输入滤波](input-filtering.md)。

## 预检查与求解

- 检查原膝关节模型、匹配的运动轨迹、ExternalLoads XML 和测力表、足与力台对应、力台基线处理、时间同步、模型坐标和文件校验值。RRA 路线使用同一个候选的调整模型和运动。
- 保留滤波前已标定竖直力的 20 N 支撑事件。每条路线独立求解自身最长的已核实支撑范围。缺失或接触有争议的时段记录原帧号和原因。比较时再从现有输出提取共同有效帧。
- 单腿路线按同一份输入运动规定骨盆，只加载目标脚指定的力台。核对储备执行器、肌肉强度以及实际求解窗口。见[全身运行](execution.md)和[单腿运行](single-leg.md)。

## 质量复核与交接

- 分别保存原生肌肉力、激活、执行器输出、求解日志、实际输入、配置和时间映射。
- 核对逐帧收敛、激活触顶、储备和残余、缺失数据及有效窗口。保留失败帧标记，积分或曲线比较不跨缺失间隔。
- 需要做 JRA 时，沿用同一路线的模型、运动、外力与原生执行器力文件。保存关节坐标系、单位和已核实的时间覆盖。
